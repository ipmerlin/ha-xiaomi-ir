# Xiaomi IR Local

Локальная интеграция Home Assistant для **`chuangmi.ir.v2`**. Создаёт устройство
и стандартную сущность `remote` с действиями `remote.send_command`,
`remote.learn_command`, `remote.delete_command`. Настройка — через интерфейс.

Версия: **0.1.0**. Целевая версия Home Assistant: **2026.10 и новее**.
Совместимость с будущими версиями требует проверки.

## Установка через HACS

[Добавить репозиторий в HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=ha-xiaomi-ir&category=integration)

1. Откройте **HACS → ⋮ → Пользовательские репозитории**.
2. Добавьте `https://github.com/ipmerlin/ha-xiaomi-ir`, тип — **Интеграция**.
3. Найдите **Xiaomi IR Local** и нажмите **Скачать**.
4. Перезапустите Home Assistant.
5. Добавьте **Xiaomi IR Local** в разделе **Настройки → Устройства и службы**
   и введите IP-адрес и токен устройства.

Если компонент уже установлен вручную, HACS возьмёт файлы того же домена
`xiaomi_ir` под управление. Создавать вторую запись интеграции не требуется.

## Ручная установка

1. Распакуйте `xiaomi_ir-0.1.0.zip` в каталог конфигурации Home Assistant.
   Должен получиться путь `/config/custom_components/xiaomi_ir/manifest.json`.
2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Xiaomi IR Local**.
4. Введите имя, IP-адрес устройства и его токен из 32 шестнадцатеричных символов.
5. Выберите комнату. В устройстве появится сущность `remote`, например
   `remote.xiaomi_ir`. Фактическое имя проверьте в карточке устройства.

Токен вводится только в Home Assistant, хранится стандартным механизмом config
entries и не включается интеграцией в журналы или атрибуты сущностей. Обращайтесь
с резервными копиями HA как с файлами, содержащими секреты.

Home Assistant должен иметь доступ к устройству по локальной сети, UDP 54321.
Рекомендуется закрепить адрес в DHCP. Xiaomi-аккаунт для этой интеграции не нужен.
Для одной физической коробки используйте одну интеграцию: параллельное обучение
через штатную `xiaomi_miio`, Mi Home или другой клиент может мешать захвату кодов.

Изменить IP или токен: меню интеграции → **Перенастроить**. Токен вводится заново;
подключение к другой физической коробке отклоняется, команды сохраняются.

## Обучение

Откройте **Инструменты разработчика → Действия**, выберите `remote.learn_command`.
Укажите вашу сущность, имя управляемого прибора и кнопки. YAML ниже — пример
вызова действия, а не настройка интеграции через `configuration.yaml`.

```yaml
action: remote.learn_command
target:
  entity_id: remote.xiaomi_ir
data:
  device: tv
  command:
    - power
    - volume_up
  command_type: ir
  timeout: 30
```

Следуйте уведомлениям Home Assistant: направьте обычный пульт на Xiaomi IR и
нажмите указанную кнопку. Для каждой команды отводится отдельное время ожидания.
Каждая успешно принятая команда сразу сохраняется. Повторное обучение той же
пары `device` / `command` заменяет её код; при ошибке прежний код сохраняется.

## Отправка

```yaml
action: remote.send_command
target:
  entity_id: remote.xiaomi_ir
data:
  device: tv
  command: volume_up
  num_repeats: 2
  delay_secs: 0.4
```

Можно передавать список команд, Xiaomi `raw:<base64>[:частота[:длина]]` или
`pronto:<Pronto Hex>[:повторы[:длина]]`. Форматы Broadlink `b64:` и Xiaomi `raw:`
различаются: коды нельзя переносить простой заменой префикса.

Обученные имена обязательно сопровождаются `device`. Это пространство имён
команд, а не автоматически созданная сущность телевизора или кондиционера.
`hold_secs` и `alternative: true` пока не поддерживаются и вызывают явную ошибку.
Поддерживается только ИК, без RF.

## Удаление

```yaml
action: remote.delete_command
target:
  entity_id: remote.xiaomi_ir
data:
  device: tv
  command: volume_up
```

Удаляются имена из библиотеки Home Assistant. Это не команда очистки памяти
самого Xiaomi. Библиотека хранится в
`/config/.storage/xiaomi_ir_<mac>_commands` и переживает перезапуск, выгрузку и
перенастройку интеграции. После удаления интеграции файл намеренно сохраняется,
чтобы повторное добавление того же устройства восстановило команды.

## Состояние и ограничения

- `remote.turn_on` / `remote.turn_off` программно разрешают и запрещают отправку
  и обучение. Они не включают и не выключают Xiaomi или телевизор.
- Доступность Xiaomi проверяется раз в минуту. Состояние управляемой ИК-техники
  не считывается: подтверждение Xiaomi означает принятие команды передатчиком,
  а не выполнение телевизором.
- При ошибке передачи повтор автоматически не выполняется. Если ответ потерян,
  результат может быть неизвестен; проверьте прибор перед ручным повтором.
- Для обучения выбирается случайный свободный слот с предварительной проверкой,
  чтобы не принять старый код за новое нажатие. Поведение слотов и обучение
  необходимо подтвердить на реальном устройстве.

## Проверки

Локальные изолированные тесты: `python -m unittest discover -s tests -v`.
Они используют заглушки Home Assistant и miIO и не заменяют запуск в HA.
Точный результат текущей проверки — в `VALIDATION.md`.

Исходники и релизы: [ipmerlin/ha-xiaomi-ir](https://github.com/ipmerlin/ha-xiaomi-ir).
Репозиторий добавляется в HACS как пользовательский; включение в общий каталог
HACS не требуется для установки по ссылке.
