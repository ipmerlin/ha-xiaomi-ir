# Проверка версии 0.1.0

Дата: 26 октября 2026 года. Целевая версия пользователя: Home Assistant 2026.10.4.

## Выполнено

- 33 изолированных теста на Python 3.12: успешны. Заглушки находятся только
  в тестовом стенде; интеграция использует штатные API Home Assistant и python-miio.
- Проверены обучение и хранение кодов, сохранение старого кода при ошибке,
  сохранение успешно обученной части списка, восстановление библиотеки новым
  экземпляром сущности, удаление и ошибки записи.
- Проверены разделение имён команд по приборам, предварительное разрешение
  списка перед отправкой, отсутствие повторной передачи после ошибки или
  неожиданного подтверждения, блокировка одновременного обучения и передачи.
- Проверены разбор ошибочных ответов miIO, токен и MAC, форма настройки,
  перенастройка того же устройства, отклонение другой модели и другого MAC.
- Проверены вызовы setup/unload, обход кэша `info` при опросе доступности,
  ожидание завершения фоновой операции при отмене задачи.
- Исходники проверены компиляцией Python и Ruff (`E4,E7,E9,F,I`), форматирование Ruff.
- Скрипт упаковки проверяет JSON, соответствие переводов, порядок manifest,
  синтаксис Python, ZIP CRC и побайтовое совпадение файлов ZIP с исходниками.
  SHA-256 готового ZIP записан рядом с архивом.

## Подтверждено исходниками

Модель `chuangmi.ir.v2`, методы `learn/read/play`, ответы чтения и опция
`retry_count` подтверждены исходниками python-miio **0.5.12**. Эта же версия
библиотеки указана в штатной интеграции HA **2026.10.4**.

Сетевые операции выполняются в executor Home Assistant. Изменяющие запросы
miIO не повторяются автоматически (`retry_count = 0`). Служебный handshake
библиотеки может отправлять несколько пакетов; это не повтор ИК-команды.

## GitHub Actions

[Запуск проверки](https://github.com/ipmerlin/ha-xiaomi-ir/actions/runs/40307531711):
33 теста и компиляция успешны; HACS — все 10 проверок пройдены;
hassfest — 0 невалидных интеграций. Проверка брендов включена.

Предупреждение HACS: в manifest нет поля `categories`. Опубликованный Docker-образ
hassfest пока не принимает это поле, поэтому оно опущено для совместимости.
Это влияет только на группировку в каталоге, а не на установку пользовательского
репозитория. Runner также предупреждает об устаревшем Node.js 20 в используемых
Actions и автоматически запускает их на Node.js 24.

В manifest используется `python-miio>=0.5.12`, чтобы не конфликтовать
с версией библиотеки, установленной самим Home Assistant.

## Не выполнено

- Запуск компонента внутри настоящего Home Assistant 2026.10.4, его штатные
  интеграционные тесты и проверка формы в браузере.
- Проверка настоящим сетевым клиентом miIO: установка библиотеки на Windows
  остановилась на сборке `netifaces` из-за отсутствия Microsoft C++ Build Tools.
- Связь, обучение, воспроизведение, тайм-ауты и поведение свободных слотов
  на физическом Xiaomi пользователя. Токен и IP не запрашивались.

Локальные тесты не доказывают работу на реальном устройстве. Архив предназначен
для первой ручной проверки в HA. В работающий Home Assistant ничего не устанавливалось.
