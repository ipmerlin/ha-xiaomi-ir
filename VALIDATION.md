# Проверка версии 0.2.1

Дата: 26 октября 2026 года. Целевая версия: Home Assistant 2026.10.4.

## Исправление

Для miIO.ir_play поддержан успешный числовой результат 0 наряду с ok.
Варианты 0, [0] и оболочка result разбираются только для ИК-передачи.
Обучение не получает этого послабления. Boolean False и число 0.0
не приравниваются к целочисленному статусу 0.

Пример настоящего ответа miIO.ir_play с result: 0 опубликован в
[отчёте пользователя Xiaomi IR](https://community.home-assistant.io/t/google-assistant-activating-2-scripts-instead-of-1/46560).
Библиотека python-miio возвращает содержимое result своему вызывающему коду.

В сообщении ошибки теперь различаются неожиданное подтверждение и исключение
сетевой библиотеки. Токены и содержимое ответа в сообщение не включаются.
Тайм-аут, отсутствие ответа и неизвестный статус не считаются успехом.
Автоматические повторы по-прежнему отключены.

## Проверки

[GitHub Actions](https://github.com/ipmerlin/ha-xiaomi-ir/actions/runs/40313305106):

- 48 изолированных тестов пройдены локально и в CI.
- 4 теста с настоящими Home Assistant 2026.10.4, infrared-protocols 10.1.0
  и python-miio 0.5.12 на Python 3.14 пройдены. Подменена только сетевая отправка.
- Ответ 0 проходит в remote и infrared без повторной отправки.
- Штатное время последней передачи infrared меняется после результата 0.
- None, пустые ответы, False, неизвестные статусы и исключения остаются ошибками.
- Предыдущие проверки преобразования таймингов, обучения, хранения команд,
  настройки, setup/unload и сериализации операций сохранены.
- Ruff, форматирование и компиляция Python успешны.
- HACS validation и hassfest успешны; проверка брендов включена.
- Скрипт упаковки проверяет JSON, переводы, ZIP CRC и совпадение с исходниками.
  Опубликованные ZIP релиза и исходники тега повторно скачиваются и сверяются.

## Предупреждения и границы

HACS предупреждает об отсутствии categories. Опубликованный образ hassfest
не принимает это поле; оно опущено для совместимости валидаторов.
Actions сообщают об устаревшем Node.js 20 и автоматически используют 24.
python-miio также выдаёт DeprecationWarning для datetime.utcnow.

Пользователь подтвердил включение телевизора Samsung через Xiaomi в 0.2.0.
Одновременно UI показал общую ошибку передачи. Предоставленный журнал
не содержит первоначального ответа miIO, поэтому именно результат 0 на этом
устройстве не подтверждён. Дефект обработки 0 исправлен по отдельному
протокольному свидетельству и воспроизведён в тестах.

Повторная физическая проверка после обновления ещё нужна. Полный запуск
платформы в пользовательском HA и проверка браузером не заменяются тестами
контрактов. В работающий Home Assistant ничего не устанавливалось.
